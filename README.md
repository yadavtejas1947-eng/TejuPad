# TejuPad
This is a 3*3 macropad built to increase your productivity by providing shortcut button for your most important tasks like pushing code , opening some app or website , controlling your music volume etc.  This Macropad is built on QMK firmware and matrix circuit using KiCad for the schematics and Fusion for the enclosure design.
